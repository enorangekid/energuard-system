# 스토어 전체 가격검사 (통합 확장 0.28.0)

실사용 파일은 Naver-rank/shopping-rank-extension에 반영됩니다. 이 폴더는 검사 기능 소스와 독립 시험용 확장입니다. 통합 확장과 별도 시험 확장을 동시에 켜지 마세요.

## 사용
1. 통합 확장을 리로드하고 관리자 페이지를 새로고침합니다.
2. 단가표의 스토어 가격검사를 엽니다.
3. 입력란을 비우고 전체 검사 시작을 누르면 product_mapping 전체를 검사합니다. 특정 상품만 확인하려면 번호/URL을 입력합니다.
4. 현재 상품을 마친 후 일시정지합니다. 이어서 검사는 미검사 상품부터 진행합니다. 실패 상품은 결과에 남으며, 별도로 번호를 입력해 다시 검사할 수 있습니다.
5. 기본 화면은 불일치·매핑 필요·확인 불가·수집 실패만 표시합니다. 체크를 해제하면 일치·품절도 볼 수 있습니다. 화면은 최근 500행, CSV는 전체 결과를 포함합니다.

## 동작
- 시작 시 적용 단가 이력 하나를 고정합니다. 진행 중 적용 단가가 바뀌어도 기존 검사 기준은 유지됩니다.
- 새 비활성 상품 탭에서 받은 할인/옵션 응답만 사용합니다. HTTP 429가 발생했던 직접 API 요청은 하지 않습니다.
- 한 상품 처리 후 약 30초 간격으로 다음 상품을 시작합니다. Chrome 알람 지연 시 더 늦어질 수 있습니다.
- 수집 실패 시 정지합니다. 자동 재시도하지 않습니다.
- 진행 위치·옵션 결과·매핑·적용 단가 스냅샷은 이 Chrome 확장의 로컬 저장소에 남습니다. 관리자 창을 닫아도 Chrome 실행 중에는 계속 진행합니다. 브라우저 재시작 후 알람으로 미완료 작업을 이어갑니다.
- 가격 변경과 Supabase 결과 저장은 없습니다. 여러 PC 간 공유/실행 잠금과 매일 예약 실행은 아직 없습니다.
- 새 검사를 시작하면 이 브라우저의 이전 검사 결과를 대체합니다. 필요하면 먼저 CSV를 저장하세요.
