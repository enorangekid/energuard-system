# Orange Sports Web

네이버 스포츠의 경기 정보 구조와 MSN 스포츠의 뉴스 카드 구성을 참고한 Orange Sports 로컬 웹 프로토타입이다.

> 2026-09-03 결정: 공개·상업 스포츠 사이트로 출시하지 않고 개인 사용 또는 소수 사용자에게 직접 배포하는 범위로 유지한다. 현재 뉴스 수집과 외부 데이터 연동은 공개 서비스용 라이선스를 확보한 구성이 아니다.

## 현재 범위

- 스포츠 통합 홈과 MLB, NBA, EPL, UCL, F1 종목 홈
- 한국시간 기준 날짜별 경기·결과와 상단 라이브 스코어 띠
- 종목별 리그 순위 및 F1 드라이버 챔피언십
- 네이버 통합 검색의 국내 기사·개별 썸네일과 공식 리그 소식을 구분한 뉴스 카드
- 전체·국내 기사·공식 소식 필터, 통합 검색과 관심 키워드
- 기사 클릭 시 외부로 바로 나가지 않는 Orange Sports 내부 기사 리더
- 응원 팀 로컬 저장
- 데스크톱·태블릿·모바일 반응형 UI

경기 상세, 문자중계와 Windows 알림 설정 연결은 다음 단계에서 기존 Orange Sports 앱 기능을 이식한다. 뉴스 카드는 제목·요약 확인용이며 외부 기사 전문을 저장하거나 제공하지 않는다.

## 실행

```powershell
cd orange-sports-web
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 연다. 포트를 바꾸려면 `ORANGE_SPORTS_PORT` 환경변수를 사용한다.

## 데이터 출처

- MLB 경기·순위: MLB Stats API
- NBA, EPL, UCL 경기·순위: ESPN 공개 응답
- F1 일정·챔피언십: OpenF1
- 국내 기사: 네이버 뉴스 통합 검색 결과(장애 시 Google News 한국어 RSS 대체)
- 공식 소식: 공식 사이트 검색 결과 및 MLB.com 공식 RSS

외부 기사 본문은 복제하지 않고 원문으로 연결한다.

## 집에서 이어서 할 일

1. `npm start`로 현재 홈·종목 전환·일정·순위·뉴스 렌더링 확인
2. `../orange-sports/`의 MLB 경기 상세 화면부터 이식
3. NBA → EPL → UCL → F1 순서로 상세 화면 추가
4. Windows 알림 클릭 시 해당 로컬 경기 상세로 이동하도록 연결
5. 기능을 추가할 때마다 `npm run check` 실행

현재 서버는 보안을 위해 `127.0.0.1`에만 바인딩되어 같은 PC에서만 접근한다.
