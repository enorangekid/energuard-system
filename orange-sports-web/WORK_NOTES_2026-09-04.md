## 번역 관련 현재 결정

- 현재 무료 번역기는 MyMemory를 사용하며 일일 한도가 작다.
- 한도가 남아 있으면 기사 클릭 시 ESPN 본문 문단을 한국어로 번역한다.
- 한도가 소진되면 한 문장짜리 요약으로 되돌아가지 않고, 확보한 영문 본문 여러 문단을 표시한다.
- 웹을 Chrome에서 개인적으로 사용할 때는 Chrome의 `한국어로 번역` 또는 `영어 항상 번역`을 쓰는 것이 가장 간단하다.
- 서비스 안에서 항상 자동 번역해야 한다면 다음 후보는 Azure Translator F0(월 200만 자), DeepL API Free(월 50만 자), Google Cloud Translation(월 50만 자)이다.
- API 키를 연결하게 되면 키는 서버 환경변수나 `.env`에만 저장하고 브라우저 코드와 GitHub에는 넣지 않는다.

## 알려진 한계

- 국내 기사 전문은 제공하지 않고 검색 결과의 제목과 요약만 보여준다.
- 뉴스 썸네일은 검색 결과에 원본 이미지 주소가 없거나 언론사가 외부 로딩을 막으면 대체 카드가 표시된다.
- 무료 번역 서비스는 일시적인 429 오류와 일일 한도가 있어 공개 서비스의 기반으로는 적합하지 않다.
- 현재 외부 데이터와 뉴스 연동은 개인 사용 또는 소수 사용자 테스트를 전제로 한다. 상업 공개 전에 공급처 약관과 재배포 권한을 다시 검토해야 한다.
- 국내 종목의 일정·순위·선수 기록은 아직 뉴스 중심 화면이며 데이터 공급처를 정하지 않았다.

## 이어서 작업할 때

1. `cd orange-sports-web` 후 `npm start` 실행
2. `http://127.0.0.1:4173`에서 종목별 뉴스와 ESPN 기사 상세 확인
3. 번역 방식을 Chrome 페이지 번역으로 유지할지 공식 번역 API로 전환할지 결정
4. 기존 `orange-sports` 앱에서 경기 상세·문자중계·알림 기능을 웹에 필요한 순서대로 이식
5. 수정 후 `npm run check`와 실제 브라우저 확인 수행
