# NBA Live Widget for Windows

통합관리자 페이지의 NBA 스포츠 위젯을 독립 실행형 Windows 앱으로 옮긴 버전입니다.

## 기능

- NBA 당일 경기 및 최근 포스트시즌 경기 목록
- 팀 로고, 기록, 실시간 점수와 경기 상태
- 쿼터별 스코어보드, 주요 선수, 최근 득점, 전체 문자중계
- 라이브 경기 8초 자동 갱신
- 득점/쿼터 종료 또는 모든 플레이 Windows 알림
- 응원 팀 알림 필터, 알림음 설정
- 항상 위, 오른쪽 아래 배치, 시스템 트레이, 시작 프로그램 설정

## 개발 실행

```powershell
npm install
npm start
```

## 설치 파일 빌드

```powershell
npm run build
```

완성된 설치 파일은 `final-release` 폴더에 생성됩니다.
