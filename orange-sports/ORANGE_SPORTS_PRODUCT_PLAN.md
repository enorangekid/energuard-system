# Orange Sports 제품 분리 계획

## 결정

Orange Sports는 에너가드 통합관리자와 별도 제품으로 운영한다. 통합관리자에는 스포츠 메뉴와 위젯을 두지 않는다.

궁극적인 구조는 **웹서비스가 본체**, **Windows 앱이 알림 클라이언트**인 형태다. 현재 Electron 앱의 스포츠 데이터 처리와 화면은 웹 본체를 만들 때 재사용한다.

## 제품 경계

### Orange Sports Web

- NBA, MLB, EPL, UCL, F1 종목 홈
- 날짜별 일정, 라이브 스코어와 경기 상세
- 문자중계, 박스스코어, 순위, 선수 통계, 플레이오프·토너먼트
- 팀·선수 상세 페이지
- 기사 제목, 이미지, 요약, 언론사, 원문 링크를 제공하는 뉴스 피드
- 데스크톱과 모바일 반응형 UI

### Orange Sports for Windows

- 웹서비스 화면 표시
- 시스템 트레이와 Windows 시작 시 자동 실행
- 응원 팀과 찜한 경기 백그라운드 감시
- 종목별 실시간 카드 알림
- 알림 클릭 시 웹 경기 상세로 이동

### 공통 데이터 계층

- MLB Stats API, ESPN 응답, OpenF1 데이터를 공통 형식으로 정규화
- 외부 API 호출 캐시와 요청 제한 관리
- 기사 데이터는 사용 가능한 공식 RSS·뉴스 API를 우선 사용
- API 키나 비공개 설정은 브라우저·Electron 렌더러에 넣지 않고 서버에서 관리

## 현재 저장소 상태

- 독립 Windows 앱: 이 디렉터리 전체
- 통합관리자에서 스포츠 위젯 진입 버튼, 패널 HTML, 스크립트 로딩 제거 완료
- `legacy-admin-widget/widget-sports.js`: 통합관리자에서 분리해 보존한 레거시 참고 소스
- `../css/panels.css`, `../css/style.css`의 `.sp-*`: 실행 화면에서는 사용되지 않는 레거시 스타일
- `ORANGE_SPORTS_HANDOFF.md`: 기존 구현 내역과 API·알림 동작 기록

레거시 파일과 스타일은 웹 본체로 필요한 코드를 이식한 뒤 별도 커밋에서 삭제한다. 지금 바로 삭제하지 않는 이유는 기존 순위·플레이오프·한글화 로직을 비교 자료로 사용하기 위해서다.

## 권장 진행 순서

1. 별도 `orange-sports-web` 프로젝트 생성
2. 공통 종목 내비게이션과 일정 홈 구축
3. 현재 MLB 경기센터를 첫 번째 상세 페이지로 이식
4. NBA, EPL, UCL, F1 상세 화면 순차 이식
5. 서버 캐시·정규화 계층 분리
6. 뉴스 피드 추가
7. Electron 앱을 웹 본체와 연결하되 알림 기능은 로컬에서 유지
8. 이식 완료 후 통합관리자의 레거시 스포츠 JS·CSS 제거

## 배포 원칙

- 통합관리자 배포와 Orange Sports 배포는 서로 독립한다.
- Orange Sports 웹 UI 변경은 설치 파일 재배포 없이 반영한다.
- Windows 전용 기능이나 보안 변경이 있을 때만 설치 프로그램 버전을 올린다.
- MSN·네이버 화면은 정보 구조 참고용으로만 사용하고 기사 본문을 복제하지 않는다.
- 기존 설치본의 정상 업그레이드를 위해 `appId`의 과거 식별자는 당분간 유지한다. 별도 저장소와 자동 업데이트 체계가 준비된 뒤 마이그레이션 계획과 함께 변경한다.
