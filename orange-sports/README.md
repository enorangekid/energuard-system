# Orange Sports for Windows

Orange Sports의 독립 실행형 Windows 클라이언트입니다. 에너가드 통합관리자와 런타임·설정·배포를 공유하지 않으며 현재 NBA, MLB, EPL, UCL, F1을 지원합니다. (버전 2.6.0)

앞으로는 스포츠 웹서비스를 본체로 두고 이 앱은 Windows 알림·트레이·자동 실행을 담당하는 클라이언트로 발전시킨다. 제품 분리와 웹 전환 기준은 `ORANGE_SPORTS_PRODUCT_PLAN.md`를 참고한다.

## 기능

- NBA 당일 경기 및 최근 포스트시즌 경기 목록
- 팀 로고, 기록, 실시간 점수와 경기 상태
- 네이버 스포츠형 종목 칩, 월 이동, 7일 날짜 스트립, 리그별 한 줄 경기 일정
- 쿼터별 스코어보드, 주요 선수, 최근 득점, 전체 문자중계
- 라이브 경기 8초 자동 갱신
- 득점/쿼터 종료 또는 모든 플레이 카카오톡형 카드 알림
- 우측 하단 자동 표시, 7초 후 자동 닫힘, 마우스 오버 일시 정지
- 알림 클릭 시 해당 경기 문자중계 열기
- 새 알림은 기존 알림 위로 좁은 간격으로 쌓이며 일반 알림은 최대 6개까지 표시
- 알림 카드에 양 팀 로고 표시
- 알림별 고정(압정형 토글) 및 설정의 모든 알림 고정
- 알림 투명도 조절(프라이버시용 최저 15%)과 표시 중인 알림 전체 닫기
- 이벤트 선수 얼굴 표시, 사진이 없으면 회색 실루엣 아바타로 대체
- 순위 탭: 종목별 팀 순위표, 선수 스탯 순위, 플레이오프/토너먼트 대진, 과거 시즌 선택
- MLB 이닝별 R/H/E 스코어보드, 타자·투수, B/S/O, 주자, 최근 투구, 득점 장면, 전체 타석 기록
- EPL/UCL 날짜별 경기, 득점·카드·교체 이벤트, 주요 팀 기록
- F1 시즌 일정과 세션별 한국시간, 서킷·국가 정보
- F1 완료 세션 결과, 드라이버 사진, 타이어 전략, 피트스톱, 레이스 컨트롤 기록
- F1 드라이버·컨스트럭터 챔피언십 순위와 과거 시즌 선택
- NBA/MLB/EPL/UCL 종목별 응원 팀 알림 필터
- 진행 중인 경기별 알림 추가·해제(응원 팀과 별도로 선택 가능)
- 현재 화면의 종목과 관계없이 모든 종목의 응원 팀·찜한 경기를 동시에 백그라운드 감시
- MLB 플레이 및 EPL/UCL 득점·퇴장 실시간 카드 알림
- NBA 각 쿼터·연장 종료, MLB 매 이닝 초·말 종료, EPL/UCL 전반전·경기 종료 시 현재 점수 알림
- 알림음 설정
- 알림창 포인트 색상으로 NBA·MLB·EPL·UCL 종목 구분
- Orange Sports 전용 앱·트레이·설치 프로그램 아이콘
- 항상 위, 오른쪽 아래 배치, 시스템 트레이, 시작 프로그램 설정

## 개발 실행

```powershell
npm install
npm start
```

## 설치 파일 빌드

```powershell
npm run build
```

완성된 설치 파일은 `final-release` 폴더에 생성됩니다.

## 데이터 관련 주의

NBA/EPL/UCL은 ESPN 공개 응답, MLB는 MLB Stats API, F1은 OpenF1을 사용합니다. 공식 제휴 API 계약이 아니므로 제공처의 응답 구조나 정책 변경 시 보수가 필요합니다.

OpenF1 무료 범위는 2023년 이후 과거 세션이며 가입이나 API 키가 필요 없습니다. 세션 시작 30분 전부터 종료 30분 후까지의 실시간 데이터는 무료로 열리지 않으므로 앱에서도 유료 라이브 안내만 표시합니다. 무료 요청 제한(초당 3회, 분당 30회)을 지키기 위해 상세 데이터는 순차 요청 후 캐시합니다.
