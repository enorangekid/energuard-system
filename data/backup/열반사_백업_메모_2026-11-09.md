# 열반사단열재 단가 백업 메모 (2026-11-09)

## 백업 파일
- `pricing-hankook-reflective_2026-11-09.js` — 열반사 단가 전체 (제품·원가·판매가, 채널별 상품번호·옵션ID·배송비·쿠폰 계산)
- `pricing-hankook-coupon_2026-11-09.js` — 한국단열 네이버 쿠폰 기록 (열반사 쿠폰은 이 파일의 표·새 쿠폰 묶음에 들어 있음)
- 되돌릴 때: 위 파일을 `js/` 안의 원래 이름(날짜 뺀 이름)으로 덮어쓴다.
- 판매가의 실제 값(사용자가 화면에서 고친 값)은 DB(`hk_settings`)에 저장되고, 코드 파일에는 기본값만 있다. 이 백업은 코드 기본값이다.
- 스토어 판매가(쿠폰 금액만큼 올린 값)는 `js/pricing-hankook-store-price.js`에 있고 이번 백업에는 안 넣었다.

## 가격 계산 공통
- 판매가 기준 가격이 한 곳이고, 채널별로 아래 공식으로 등록가를 만든다.
- 롤(`…_R`) 배송비는 롤 지름 기준: 5T 50m 20,000 / 6T 25m 15,000 / 10T 25m 20,000 / 13T 20m 22,000 / 20T 10m 18,000. 모든 채널이 같은 값을 쓴다 (2026-10-21).
- 롤 판매가는 배송비를 낮춘 만큼 올려서 고객 총액은 그대로 둔다 (5T 50m +7,000 / 6T 25m +5,000 / 10T 25m +7,000 / 13T 20m +10,000 / 20T 10m +8,000).

### 쿠팡
- 등록가 = (판매가 + 배송비) × 1.16, **100원 단위 반올림** (ESM·11번가의 올림과 다름).
- 쿠폰: 배송비 있는 상품 10%, 무료배송 상품 12%가 기본. 예외는 단가표에서 직접 지정함.
  - 롤 상품(8232412643·5465024346) 12% 강제, 5T 50m 고급형 한쪽접착은 쿠폰 상한 30,000.
  - 신규 5M(9806191720)은 10% (무료배송인데도 12%가 아님, 사용자 지시).
- 1M 상품(178569244) 5T~13T 옵션에 조건부 다운로드 쿠폰: 2만원↑ 3천원 / 3만원↑ 5천원 / 5만원↑ 7천원. 가격 계산에는 안 넣고 메모만.
- 반품/교환비: 단가표 값과 WING 값이 달라도 중요하지 않음 (예: 8255306549 단가표 12,000, WING 14,000). 할 일로 올리지 않는다.
  - 8232412643·5465024346 40,000, 9806191720 10,000은 임시값이다.
- 신규 5M 9806191720 (2026-11-05 등록): 옵션 14개. 11/6부터 광고. 첫 성과는 11/6~9 주문 1건.
- 가격 변경 한도: 1회 −50% / +100%. 한 묶음 안에 위반이 있으면 전체 실패.
- 일괄 업로드 엑셀이 할인율 기준가(정상가)를 못 바꾸는 경우가 있어 그럴 땐 WING에서 직접 수정.
- 열반사 8397602717·5472028429는 쿠팡 쪽 오류로 상세 HTML 작업 보류.
- 과도한 반품비 증빙 요청 이력: 174891106(스티로폼), 8255306549(열반사 2M 판, 2026-11-06 서면 소명 전송, 마감 11-11). 대신화물택배·수량별 운임 유동 설명. 쿠팡이 다시 안내하기 전엔 먼저 꺼내지 않는다.

### 옥션·G마켓 (ESM)
- 옵션 하나가 단품 상품 하나 (각자 마스터상품번호·상품번호).
- 최종 판매가 = (판매가 + 배송비) × 1.08 을 **100원 올림**.
- 1M 5T~13T 배송비 4,500 (한국단열 채널의 4,300과 다름), 20T~50T 11,000, 10m 무료배송.

### 11번가
- ESM과 같은 계산식 (×1.08, 100원 올림). 마스터 4개 그룹 (롤 1549579106 / 5T~13T 1M 1549043324 / 20T~50T 1M 1661569991 / 10m 1671441485).
- 업로드 엑셀은 **.xls (97-2003)** 로 만들어야 올라간다 (.xlsx 안 됨).

### 홈페이지
- 상품ID는 네이버 번호가 아니라 내부 목록 번호 (짧은 숫자: 16, 17, 26~31).
- 비접착/한쪽접착 옵션 2개가 상품ID 하나를 공유.
- 반품/교환비는 전부 30,000/60,000 고정. 롤 상품만 있고 1M·2M은 없다.

## 상품 구성에서 알아둘 것
- 1M 상품은 수량 N = N m를 이어서 발송 (1m 단위 판매).
- 2M 판형은 1m x 2m 낱개. 수량이 적으면 롤로 말아 배송 가능. 대신화물택배.
- 13T부터 일반형은 없고 고급형 비접착/한쪽접착만. 40T·50T 2M은 고급형 비접착만 (10985932386 = 40T 2M).
- 벽면 시공은 20T까지 권장.
- 10683699346 = 빙어낚시 텐트용 20T~50T 2M 상품 (쿠폰 500원, 쿠폰 표에는 14,500 배송비).
- 최근 일시적으로 핑크 폼지 대신 아이보리(흰색) 폼지가 일부 출고됨 (원자재 수급, 2026-11-09 고객 문의). 규격·사양은 동일하다고 안내.
